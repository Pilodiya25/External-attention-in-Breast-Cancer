# External-attention-in-Breast-Cancer

This repository contains code for the manuscript:
"Classifying Breast Cancer Subtypes Using Multi-Omics Data via External Attention-Based Deep Learning Model"

## Contents
- `Feature_Selection_Code.ipynb`: Feature Selection script
- `Pilodiya_External_attention_DNN.ipynb`: External Attention based Deep Neural Network (Training and tuning) script

## How to Run

Above scripts are in Python Notebook files and can be executed in Jupyter notebooks

## Datasets Information

mRNA expression, DNA methylation, and miRNA expression
dataset from moBRCA-net study. Details are provided in the Research paper as well.
